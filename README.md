## 🔧 O que eu faço no dia a dia

- **Data Lakehouse & ELT** — ingestão de tabelas SAP no lake, contratos de schema em YAML,
  frameworks parametrizados que evitam um pipeline novo a cada tabela.
- **PySpark & SQL em escala** — transformação, deduplicação, SCD, reconciliação de fontes divergentes.
- **Orquestração & CI/CD** — Azure DevOps (pipelines, boards, PRs), Git flow, revisão de código.
- **Qualidade de dado** — validar preenchimento e semântica *antes* do join; número que não bate é bug, não é "comportamento esperado".
- **Automação com LLM** — agentes que operam pipelines, revisam PRs e geram documentação técnica.

## 🧭 Como eu trabalho

- Solução **parametrizada** antes de solução hardcoded.
- **Backup e validação em sandbox** antes de qualquer coisa em produção.
- Plano escrito (riscos, impacto, decisões pendentes) antes de mexer no que já roda.
- Documentação é parte da entrega, não sobra de fim de sprint.
